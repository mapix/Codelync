# Codex imageView 与按需图片加载

## 原因和行为

原 Codex owner 提供 `imageView` item，包含 item ID、路径和原生时间，
没有文本或通常的工具 result。旧投影未处理此类型，跳过了整条可见消息。

修复保留原 item/turn ID 与顺序。实时消息、最近页与历史页只传
`nativeImageId` 和文件名，正文显示占位图。点击后才发送会话加密的
`native-image-read` RPC。路径只从该会话的原生 item 中取得；任意路径、
其他会话的 image ID、失效 owner/lease 均被拒绝。

图片经过限长读取与常规图片格式检查后，按会话 blob key 加密上传。
成功 ref 先写入加密检查点再返回，重复点击、重连与重启复用该 ref。
手机预览打开后才下载、解密，复用现有缩放、平移与关闭组件。
缺失或超限图片在预览中显示可重试错误，不影响正文同步。
