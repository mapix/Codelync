# 按需图片压缩、加载与下载

## 行为

- 正文同步仅传图片占位标记；点击后才读取并压缩原图片。
- Mac 生成不含原 EXIF 的 JPEG，按实际输出字节数调整画质/尺寸。
  加密附件最多 500,000 字节，原文件保留。旧原图缓存与新压缩策略隔离。
- 手机预览顶部提供下载按钮，使用已加载的图片打开系统保存菜单，
  可保存到相册/文件；菜单关闭后清理缓存文件，不额外获取原图。

## 加载失败的修复

1. Sync 保留初始化时的通道清单，自动切换后的新入口可能不在该清单中。
   下载认证改为读取连接 owner 已保存的当前配对凭据，并确认账户、peer、
   设备身份一致。原凭据和未知操作不被改写或重放。
2. `URL.host` setter 在没有新端口时保留原端口。本机附件地址改写到公网
   HTTPS 后曾错误保留本机服务端口。现在分别设置协议、hostname、port，
   清除 HTTPS 的旧端口，保留 Relay 前缀，外部存储 URL 不改写。
3. 新图像库的平台包只导出原生二进制，旧打包器误将它们视为未安装的
   optional dependency。打包器现在按 Node 搜索路径定位清单；签名包内
   Node 已实际加载原生库并编码 JPEG。图像库只在点击压缩时加载。
