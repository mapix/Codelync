开始之前

支持哪些桌面应用和设备？

Mac 0.6.1 支持 Codex、Antigravity Desktop 和 Claude Desktop（Gateway），可用操作依各应用的桌面状态与已确认能力而定。接入应用不代表控制完全相同，Claude Desktop 完整正式控制仍在验证。Mac 面向 Apple Silicon、macOS 14+。

为什么暂时没有 iPhone 下载按钮？

iPhone 尚无公开 App Store 或 TestFlight 发行，目前需取得源码仓库访问权限后自行构建。带个人设备登记信息的开发包不提供公共下载。

连不上 Mac 怎么恢复？

在 Mac 打开 CodeLight 并确认服务已开始，检查两端网络，然后重试或选择已保存的连接。手机保留已缓存的会话和草稿。全部旧连接都失效时，再扫描 Mac 当前二维码。

Mac 已连接，原应用却离线了？

打开对应的 Codex、Antigravity Desktop 或 Claude Desktop，再重试会话读取。已保存的消息仍可阅读；尚未确认的操作保持不可用。

操作显示“结果未确认”怎么办？

先点“检查结果”，并在原桌面应用确认操作状态。CodeLight 保留原操作编号，不会自动再提交一次。

为什么视频不能打开？

附件只在点击后读取。视频上限为 1,000,000 字节（1 MB）；已知超限的视频不下载、不播放，也不保存。无法确认大小或读取权限时会显示不可用。

可以使用自己的公网 Relay 吗？

可以。在 Mac 的“配置 Relay”保存兼容的 HTTPS 服务地址和访问密钥，随后与本地网络、Cloudflare 独立启用。手机继续扫码，无需填写服务器。Cloudflare 临时地址可能在重启后改变；已配置 Relay 保持其认证连接。

“未确认”和流量统计分别代表什么？

“未确认”表示尚未取得可靠的原会话状态，不能当作空闲或零。流量统计是 CodeLight 的网络接口字节，不代表模型 token 或完整网络开销。

这是桌面应用的官方产品吗？

CodeLight 是独立项目，采用 MIT 许可并保留 Happy 组件的归属，不隶属于 OpenAI、Anthropic 或 Google。源码仓库需要访问权限；不可用的桌面能力会明确显示。
