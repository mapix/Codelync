连接起来

从电脑，到口袋。

先在原桌面应用配置好 Gateway，再安装 Mac 伴侣和 iPhone App。Codelync 配对无需另注册账号或安装 VPN。

  1. 1

    安装 Mac 伴侣

    下载预览版，放入 Applications 并打开。“开始”和“暂停”控制 Codelync 服务；在“来源”中选择桌面应用，重启后保留选择。

  2. 2

    准备 iPhone App

    TestFlight Beta 即将开放。也可直接使用公开源码，按说明使用 Xcode 和自己的 Apple 开发签名构建。

    查看构建说明 ↗
  3. 3

    扫码，继续会话

    扫描 Mac 当前二维码，手机自动选择可用连接。进入项目和会话后，可从设置或顶部连接图标切换连接方式。

  4. 4

    按需开启远控

    远控默认关闭。先在手机“设置”的功能开关中开启“远程桌面”，再在 Mac 开启远控并授权屏幕录制和辅助功能。手机从独立入口进入横屏，按需选择显示器、清晰度和帧率。

开始之前

支持哪些桌面应用和设备？

当前发行面向已配置 Gateway 的用户，接入 Codex、Antigravity Desktop 和 Claude Desktop（Gateway）。可用操作依原应用状态和已确认能力而定；Claude Desktop 完整正式控制仍在验证。Mac 需要 Apple Silicon、macOS 14+。独立 CLI/TUI 尚未接入。

如何安装 iPhone App？

TestFlight Beta 即将开放；通过外部测试审核后，本页会显示真实加入链接。也可直接使用公开源码自行构建，个人设备开发包不公开下载。

连不上 Mac 怎么恢复？

在 Mac 打开 Codelync 并确认服务已开始，检查两端网络，然后重试或选择已保存的连接。顶部固定图标集中显示连接状态、错误详情和恢复操作。手机保留消息和草稿，可读入口会保留，让实时更新单独恢复。全部旧连接都失效时，再扫描 Mac 当前二维码。

Mac 已连接，原应用却离线了？

打开对应的 Codex、Antigravity Desktop 或 Claude Desktop，再重试会话读取。已保存的消息仍可阅读；尚未确认的操作保持不可用。

操作显示“结果未确认”怎么办？

先点“检查结果”，并在原桌面应用确认操作状态。Codelync 保留原操作编号，不会自动再提交一次。

为什么视频不能打开？

附件只在点击后读取。视频上限为 1,000,000 字节（1 MB）；已知超限的视频不下载、不播放，也不保存。无法确认大小或读取权限时会显示不可用。

如何开启远程桌面？

在手机“设置”的功能开关中开启“远程桌面”，并在 Mac 开启远控、按提示授权。手机可全屏观看、选择显示器和画质、控制鼠标与滚动，切换 macOS 桌面或打开 Mission Control。公网远控还需可达的媒体通路，部分网络需要自建媒体服务器和 TURN 转发。真机与不同网络的反馈仍在收集。

可以使用自己的公网 Relay 吗？

可以。在 Mac 的“配置 Relay”保存兼容的 HTTPS 服务地址和访问密钥，随后与本地网络、Cloudflare 独立启用。手机继续扫码，无需填写服务器。Cloudflare 临时地址可能在重启后改变；已配置 Relay 保持其认证连接。

“未确认”和流量统计分别代表什么？

“未确认”表示尚未取得可靠的原会话状态，不能当作空闲或零。流量统计是 Codelync 的网络接口字节，不代表模型 token 或完整网络开销。

这是桌面应用的官方产品吗？

Codelync 是独立项目，采用 MIT 许可并保留 Happy 组件的归属，不隶属于 OpenAI、Anthropic 或 Google。日常订阅使用建议选择各家的官方 App；Codelync 面向已有 Gateway 配置的用户。源码仓库已公开。
