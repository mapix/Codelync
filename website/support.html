支持

Codelync 面向已配置 Gateway 的用户，接入 Codex、Antigravity Desktop 和 Claude Desktop（Gateway）的已确认原生能力。日常订阅使用建议选择各家的官方 App；独立 CLI/TUI 尚未接入。

连不上 Mac

  1. 在 Mac 打开 Codelync，确认服务已开始。
  2. 检查两端网络，从手机顶部连接图标查看原因、重试或选择已保存的连接。
  3. 若全部已保存连接失效，扫描 Mac 当前二维码。已有消息和草稿会保留。

会话或操作不可用

Mac 可连接不代表原桌面应用已连接。打开对应原应用，再重试读取。“未确认”不代表空闲或零；“结果未确认”时先检查结果，并在原应用确认，避免重复提交。

远控与附件

远控默认关闭：在手机“设置”的功能开关中开启“远程桌面”，并在 Mac 启用和授权。公网远控还需要可达的媒体通路。附件点击后才加载；视频超过 1,000,000 字节（1 MB），或大小、读取权限未确认时，保持不可用。

iPhone Beta

以官网首页的当前状态为准；只有外部测试通过审核且测试组已开放时，才显示 Apple TestFlight 加入链接。不要安装来历不明的手机包或配置描述文件。

Support

Codelync is for people with an existing Gateway configuration and connects the confirmed native capabilities of Codex, Antigravity Desktop and Claude Desktop (Gateway). For everyday subscription use, we recommend the official apps. Standalone CLI/TUI apps are not connected.

Cannot connect to Mac

  1. Open Codelync on Mac and make sure its service is started.
  2. Check both networks. Use the fixed connection icon on iPhone for details, retry or a saved route.
  3. If every saved route has expired, scan the current Mac QR code. Existing messages and drafts remain.

Unavailable sessions or actions

A reachable Mac does not establish that the original desktop app is connected. Open the corresponding app and retry reading. Unconfirmed does not mean idle or zero. For an unconfirmed action result, check the result and confirm it in the original app before submitting anything again.

Remote desktop and attachments

Remote desktop is off by default. Enable its feature switch in iPhone Settings, then enable it and grant permissions on Mac. Public access also needs a reachable media path. Attachments load only after a click. Videos over 1,000,000 bytes (1 MB), or with unknown size/read access, remain unavailable.

iPhone beta

Use the current status on the homepage. An Apple TestFlight join link appears only after external review approval and an enabled test group. Do not install phone packages or configuration profiles from unknown sources.

Feedback

Email mapix.me@gmail.com. You can also use repository issues.

Include Mac/iPhone app versions, OS versions, network type, reproduction steps and a reviewed error summary. Never send passwords, model keys, QR codes, pairing invitations, private conversations, device registration files or unchecked full logs.

サポート

Codelync は Gateway を設定済みの方のためのアプリです。Codex、Antigravity Desktop、Claude Desktop（Gateway）の確認済みネイティブ機能に接続します。通常のサブスクリプション利用には公式アプリをおすすめします。独立した CLI/TUI は未対応です。

Mac に接続できない

  1. Mac で Codelync を開き、サービスの開始を確認します。
  2. 両端のネットワークを確認します。iPhone の上部接続アイコンで詳細を確認し、再試行するか保存済み接続を選んでください。
  3. すべての接続が無効な場合は、Mac の現在の QR コードをスキャンしてください。既存のメッセージと下書きは残ります。

セッションや操作を利用できない

Mac に接続できても元のデスクトップアプリへの接続が確認できるとは限りません。該当アプリを開き、読み込みを再試行してください。「未確認」は待機やゼロを意味しません。操作結果が未確認の場合は、結果と元のアプリを確認してから再度送信してください。

リモートデスクトップと添付ファイル

リモートデスクトップは初期設定でオフです。iPhone の設定で有効にし、Mac 側でも有効化して必要な権限を許可します。外部接続には到達可能なメディア経路も必要です。添付ファイルは選択時に読み込みます。動画が 1,000,000 バイト（1 MB）を超える場合や、サイズまたは読み取り権限が未確認の場合は利用できません。

iPhone Beta

ホームページの現在の状態をご確認ください。外部テストが承認され、テストグループが公開されてから Apple TestFlight の参加リンクを表示します。出所不明のアプリや構成プロファイルをインストールしないでください。
